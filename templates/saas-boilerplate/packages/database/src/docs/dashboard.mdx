Signed-in users work in the `(home)` route group: `apps/web/app/(home)`. This is where your product lives.

## The app shell

`app/(home)/layout.tsx` wraps every signed-in page with:

- the **sidebar** (`components/home/AppSidebar.tsx`): logo and name from the CMS, navigation, the admin group for admins, the workspace switcher with the Organizations module, and the user menu;
- the **user menu** at the bottom of the sidebar: credits (Billing module), **Settings**, theme switch and sign-out;
- a **guest banner** when the read-only demo account is signed in;
- a header with the sidebar toggle and breadcrumbs.

The layout prefetches landing content on the server (for the logo and name) and hydrates it to the client.

## Settings

The Settings dialog (`packages/ui/src/components/home/SettingsDialog.tsx`) has these sections:

| Section | Contents |
| --- | --- |
| My Account | Name, avatar upload, change or set password, delete account |
| Sessions | Active sessions with device and IP, revoke any of them |
| Plans & Billing | Credit balance, buy credits, transaction history (Billing module) |
| API Keys | Create, list and revoke API keys (API Keys module) |

## Your home page

In a downloaded project, `app/(home)/page.tsx` is an intentionally empty page:

```tsx
"use client";

export default function Page() {
  return <div className="flex-1 p-6" />;
}
```

Replace it with your product. In the open-source repository this page is the SaaS Forge download wizard instead.

## Adding a page

Create a folder under `app/(home)`. The middleware protects it automatically (any path not listed in the route policy requires a session).

```tsx
// apps/web/app/(home)/reports/page.tsx
import { getQueryClient, trpc } from "@/trpc/server";
import { dehydrate, HydrationBoundary } from "@tanstack/react-query";
import ReportsList from "@/components/reports/ReportsList";

export default async function ReportsPage() {
  const queryClient = getQueryClient();
  await queryClient.ensureQueryData(trpc.reports.list.queryOptions());

  return (
    <HydrationBoundary state={dehydrate(queryClient)}>
      <ReportsList />
    </HydrationBoundary>
  );
}
```

Then add a link in `components/home/AppSidebar.tsx`. Wrap it in `isAdmin` if only admins should see it, and protect the data with `adminProcedure` either way. The full recipe is in [Adding a Feature](/landing/doc/adding-features).
