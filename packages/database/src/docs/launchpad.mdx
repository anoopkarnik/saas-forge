A saved project on SaaS Forge has a **Launchpad**: a curated walkthrough from downloaded starter to running product. This is part of the SaaS Forge platform, rather than a module shipped in the starter.

![Run locally, build your MVP, launch and operate with a project-specific checklist](/cms/v2/project-launchpad.png)

## Four phases

| Phase          | What it helps you do                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| Run locally    | Extract the starter, configure services, generate the client and start the selected apps |
| Build your MVP | Adapt branding and content, implement the product and connect its selected integrations  |
| Launch         | Review production credentials, deployment, migrations and release checks                 |
| Operate        | Review jobs, usage, logs, updates and other tools included in the project                |

Steps are filtered by saved modules, providers, platforms and deployment choice. Each gives file paths or settings, the expected result, common fixes and visible documentation links. The checklist appears immediately; it does not need an AI interview or generation step.

## Track and take it with you

Earlier applicable completed work is retained separately, while new steps are never automatically marked complete. Markdown exports and the downloaded `SETUP.md` use the same curated walkthrough.

**Ask for help** optionally explains or troubleshoots the selected task with AI. You can use the checklist without that assistance. For version changes and added modules, use the [Upgrade Center](/landing/doc/upgrading).

Product end-user onboarding is a separate [optional module](/landing/doc/onboarding).
