The scaffold feature lets users download a customized copy of the SaaS Forge boilerplate: only the modules and platforms they chose, priced from the module catalog.


## Your keys never reach our servers


The server only receives non-secret choices: modules, platforms, themes and toggles. Database URLs, auth secrets and provider API keys are never sent.

- **Web and desktop:** if you import a `.env` file with secrets, the download is built from your public choices, then your browser adds the secrets to the ZIP as `apps/web/.env.local` and `packages/database/.env` (readable only by you, `0600`).
- **Mobile:** secrets are not collected. Add them after download by following `SETUP.md`.

`/api/scaffold` rejects any request that contains a secret with `400 secret_not_accepted`, and server logs redact secret-looking fields.


## What the ZIP contains


- The project, compiled for your modules and platforms, without `node_modules` or build output.
- `.env` files for each platform with your public choices, plus `.env.example` templates.
- `SETUP.md`: the accounts to create and every env var to fill, with where to find each one.
- `pnpm-lock.yaml`, pruned to your selection, so `pnpm install --frozen-lockfile` works on CI and Vercel.
- `.boilerplate-version`, used by upgrades.


## API


**POST** `/api/scaffold` (signed-in session)

```json
{
  "name": "my-awesome-saas",
  "modules": ["billing", "ai"],
  "envVars": { "NEXT_PUBLIC_URL": "https://example.com", "NEXT_PUBLIC_PLATFORM": "web,mobile" },
  "expectedTotalCredits": 50
}
```

| Response | Meaning |
| --- | --- |
| `200` | The ZIP stream. Credits are charged once and recorded in the scaffold ledger. |
| `400 secret_not_accepted` | `envVars` contained a secret. The `keys` field lists them; nothing was built or charged. |
| `403` | Not enough credits, or the origin is not allowed. |
| `409 price_changed` | `expectedTotalCredits` no longer matches the catalog. Refresh prices and retry. |

Prices come from the public `scaffold.catalog` tRPC query. Saved projects can also be downloaded with an API key through `POST /api/v1/projects/{slug}/download`, which builds the same archive.


## Implementation


- `apps/web/app/api/scaffold/route.ts`: session, secret and price checks.
- `apps/web/lib/scaffold/service.ts`: `buildProjectZip`, the one builder for every download path.
- `packages/ui/src/lib/scaffold-secrets.ts`: which env vars are secrets, shared by clients and server.
- `packages/ui/src/lib/zip-append.ts`: adds the secret files to the downloaded ZIP on the device.
