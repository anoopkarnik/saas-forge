## Tools

| Tool | Version | Notes |
| --- | --- | --- |
| Node.js | 24 or newer | Required by `engines` in `package.json`. Use nvm, fnm or Volta |
| pnpm | 10.4.1 | Run `corepack enable` and the version pinned in `packageManager` is used |
| Git | any recent | Needed for upgrades and the template branch |
| Docker | optional | Runs Postgres (with pgvector) and Redis locally through `docker-compose.yml` |

Supported operating systems are macOS, Linux and Windows through WSL2.

## Services every project needs

| Service | Why | Free tier |
| --- | --- | --- |
| PostgreSQL | Users, sessions, CMS content, docs, billing and module data | [Neon](https://neon.tech/), [Supabase](https://supabase.com/), or local Docker |
| [Upstash Redis](https://upstash.com/) | Rate limits on uploads and other session routes, plus caching of CMS and docs content | Yes |
| [Resend](https://resend.com/) | Verification and password-reset emails when email sign-up is on | Yes, with a verified domain for real recipients |

Production refuses to start without `DATABASE_URL`, `NEXT_PUBLIC_URL` and a strong `BETTER_AUTH_SECRET`, and with email sign-up on it also needs an email client. See [Environment Variables](/landing/doc/env-vars).

## AI Agents module only

The Python service in `apps/backend` also needs:

- Python 3.12 or newer and [uv](https://github.com/astral-sh/uv) (`pipx install uv` or `curl -LsSf https://astral.sh/uv/install.sh | sh`).
- Postgres with the `pgvector` extension. Neon and the `pgvector/pgvector` Docker image both have it.
- A Redis reachable over TCP (`redis://…`) for the job queue. Upstash's REST API is not enough here; Docker Compose provides one locally.

## Native apps only

- **Desktop:** nothing extra for development. Building a snap needs `snapcraft`; macOS and Windows installers are built on those systems.
- **Mobile:** an [Expo](https://expo.dev/) account and the EAS CLI for cloud builds. Local iOS builds need Xcode with CocoaPods, local Android builds need Android Studio.
