Versions are the ones installed from `pnpm-lock.yaml` at the time of writing. Check `package.json` files for the exact ranges.

## Web and shared code

| Area | Technology |
| --- | --- |
| Framework | [Next.js](https://nextjs.org/) 15.5 (App Router, Turbopack in dev), [React](https://react.dev/) 19.2, TypeScript 5.7 |
| Styling | [Tailwind CSS](https://tailwindcss.com/) 4, [shadcn/ui](https://ui.shadcn.com/) on Radix UI, Framer Motion, Lucide icons |
| API | [tRPC](https://trpc.io/) 11 with [TanStack Query](https://tanstack.com/query) 5, [Zod](https://zod.dev/) 4, plus REST route handlers |
| Auth | [Better Auth](https://www.better-auth.com/) 1.5 with the admin, organization and Expo plugins |
| Database | PostgreSQL with [Prisma](https://www.prisma.io/) 7 (`prisma-client` generator and the `@prisma/adapter-pg` driver adapter) |
| Cache and rate limits | [Upstash Redis](https://upstash.com/) and `@upstash/ratelimit` |
| Email | [Resend](https://resend.com/) and [React Email](https://react.email/) |
| File storage | [Vercel Blob](https://vercel.com/docs/storage/vercel-blob) or [Cloudflare R2](https://developers.cloudflare.com/r2/) through the S3 API, images processed with sharp |
| Payments | [Stripe](https://stripe.com/) or [Dodo Payments](https://dodopayments.com/) |
| AI | [Vercel AI SDK](https://ai-sdk.dev/) 6 with OpenAI, Anthropic, Google, OpenRouter, Ollama, OpenAI-compatible endpoints and the Vercel AI Gateway |
| Logging and analytics | Winston with BetterStack (Logtail), Google Analytics 4, Vercel Analytics and Speed Insights |
