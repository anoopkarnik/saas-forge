SaaS Forge is an open-source, full-stack SaaS boilerplate. It is a `pnpm` + Turborepo monorepo with a Next.js web app, an Electron desktop app, an Expo mobile app, an optional Python AI service, and shared packages for auth, database, email, UI and logging. Sign-in, payments, a CMS-driven landing page, documentation, an admin panel, uploads, SEO and production hardening are already built, so you can start on the part that is your product.

## Two ways to use it

| | Open source | Download a boilerplate |
| --- | --- | --- |
| What you get | The whole repository: every module, every provider, all platforms, plus the SaaS Forge download platform itself | A clean starter compiled for the modules, platforms and providers you pick |
| Cost | Free, MIT licensed | Paid in credits on [saasforge.cc](https://saasforge.cc): 20 base credits plus each module's price |
| Code you carry | Everything, including the scaffold builder and release tooling | Only what you selected. Unselected modules leave no files, imports, env vars or migrations behind |
| Getting updates | `git pull` from the repository | The Upgrade Center, paid upgrade kits, or merging the published template branch |
| Best for | Learning the codebase, contributing, keeping every option open, or running your own download platform | Starting a product with exactly the code it needs |

Not sure which one fits? Read [Choose Your Path](/landing/doc/choose-your-path).

## What is inside

- **Web app** (`apps/web`): Next.js 15 App Router with auth pages, a landing site, docs, legal pages, an admin panel, tRPC API, REST routes and payment webhooks.
- **Desktop app** (`apps/desktop`): Electron, packaged as snap, AppImage, deb, dmg or nsis.
- **Mobile app** (`apps/mobile`): Expo with expo-router for iOS, Android and web.
- **AI service** (`apps/backend`, AI Agents module): FastAPI with LangGraph agents, background jobs and RAG.
- **Shared packages**: Better Auth, Prisma, React Email + Resend, shadcn/ui-based components, the AI SDK wrapper, Winston logging and Notion CMS helpers.

The full list is on [Features](/landing/doc/features).

## Design principles

- **The code is yours.** A project has no runtime dependency on SaaS Forge. Change anything.
- **One source of truth.** Shared behavior lives in the root `apps/` and `packages/`. The starter and every download are compiled from it, so a fix lands everywhere.
- **Pay for what you ship.** Optional features are modules. A download without a module contains no trace of it, and you can add it later as an upgrade.
- **Secrets stay on your machine.** The download server never receives your keys. `pnpm doctor` asks for them locally and writes your `.env` files.
- **Safe by default.** Production refuses to boot with missing or placeholder secrets. Every API route is declared in a route policy with its auth, rate limit and body-size limit, and payment webhooks are idempotent.
- **One backend for every client.** Web, desktop and mobile use the same Better Auth sessions and the same tRPC API.
