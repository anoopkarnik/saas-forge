The databases the Notion CMS reads, with the property names and types the code expects. Names are case-sensitive, and a wrong type usually shows up as an empty field: Text properties are read as rich text, while Title, Select, URL and Checkbox are read as single values.

## Landing page (`LANDING_DATABASE_ID`)

One row per product. The row whose `title` contains `NEXT_PUBLIC_SAAS_NAME` is used.

| Property | Type | Used for |
| --- | --- | --- |
| `title` | Title | Product name |
| `logo`, `darkLogo` | Files & media | Logos for light and dark mode |
| `githubLink` | URL | Navbar GitHub link |
| `githubUsername`, `githubRepositoryName` | Text | GitHub star count |
| `donateNowLink` | URL | Navbar donate link |
| `tagline`, `description` | Text | Hero text |
| `appointmentLink` | URL | Hero booking button |
| `codeSnippet` | Text | Hero command snippet |
| `videoLink` | URL | Hero video |
| `featureHeading`, `featureDescription` | Text | Features section heading |
| `testimonialHeading`, `testimonialDescription` | Text | Testimonials section heading |
| `pricingHeading`, `pricingDescription` | Text | Pricing section heading |
| `faqHeading`, `faqDescription` | Text | FAQ section heading |
| `creator` | Text | Footer credit |
| `creatorLink` | URL | Footer credit link |
| `supportEmailAddress`, `companyLegalName`, `websiteUrl`, `country`, `contactNumber`, `address`, `lastUpdated` | Text | Legal and contact pages |

## Section databases

Every section database has a relation property named **`Landing Page`** pointing to the landing page database.

| Database | Properties |
| --- | --- |
| Hero (`HERO_DATABASE_ID`) | `title` (Title), `image` (Files & media) |
| Features (`FEATURE_DATABASE_ID`) | `title` (Title), `description` (Text), `category` (Select), `image` (Files & media) |
| Testimonials (`TESTIMONIAL_DATABASE_ID`) | `name` (Title), `position` (Text), `comment` (Text), `category` (Select), `image` (Files & media) |
| Pricing (`PRICING_DATABASE_ID`) | `title` (Title), `price` (Text), `popular` (Checkbox), `description` (Text), `priceType` (Select, for example "/month"), `benefitList` (Text, comma-separated) |
| FAQ (`FAQ_DATABASE_ID`) | `question` (Title), `answer` (Text) |
| Footer (`FOOTER_DATABASE_ID`) | `label` (Title), `href` (Text), `type` (Select, the footer column) |

## Documentation (`DOCUMENTATION_DATABASE_ID`)

| Property | Type | Used for |
| --- | --- | --- |
| `Name` | Title | Page title; the slug is derived from it |
| `SaaS Landing Page` | Relation | Links the page to your landing page row |
| `Type` | Select | Sidebar category |
| `order` | Number | Position in the sidebar |

Note the documentation relation is named `SaaS Landing Page`, while section databases use `Landing Page`.
