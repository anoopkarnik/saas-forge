`create-saas-forge` creates a project from the terminal with only the modules you bought, using the same prices and archive as the web wizard.


## Sign in


Create an API key in SaaS Forge under **Settings → API Keys** with the scopes `read:me`, `read:projects`, `write:projects`, `scaffold:download` and `scaffold:upgrade`. Then:

```bash
npx create-saas-forge login
```

The key is saved to `~/.config/saas-forge/credentials.json`, readable only by you. In CI, set `SAAS_FORGE_API_KEY` instead.


## Create a project


```bash
# Interactive: pick modules and platforms
npx create-saas-forge my-app

# Non-interactive (CI)
npx create-saas-forge my-app --modules billing,ai --platforms web,mobile --yes

# Download a configuration you saved on the dashboard
npx create-saas-forge new my-app --project my-saved-project --yes
```

The CLI shows the price before charging, adds modules a selection requires (AI Agents needs AI), verifies the archive's checksum, and extracts it into `my-app`. Downloading a build you already own is free. Add `--install` to also run `git init`, `pnpm install` and `pnpm generate`.

Your keys never leave your machine: run `pnpm doctor` in the project. It asks for each value, checks it against the service and writes the `.env` files.


## Upgrade


Run inside a project created by the CLI (it reads `.saas-forge.json`):

```bash
# See what an upgrade adds and costs
npx create-saas-forge upgrade --add ai_agents --tier tier-3 --dry-run

# Buy it and unpack the upgrade kit
npx create-saas-forge upgrade --add ai_agents --yes
```

The kit contains `UPGRADE.md`, `UPGRADE_SPEC.json` and the staged changes. Follow `UPGRADE.md`, or run the upgrade-boilerplate skill in Claude Code.


## Other commands


```bash
npx create-saas-forge credits   # remaining credits
npx create-saas-forge --help
```

| Option | Meaning |
| --- | --- |
| `--api-key <key>` | Use this key instead of the saved one or `SAAS_FORGE_API_KEY` |
| `--url <server>` | Point at another SaaS Forge server (`SAAS_FORGE_URL`) |
| `--yes` | Skip confirmations (required without a terminal) |

The older `npx saas-forge` command still works but clones the whole platform repository. It prints a deprecation notice and will be removed in a later release.
